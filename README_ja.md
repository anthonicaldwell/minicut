# minicut

**minicut** は、Linux デスクトップ環境向けに設計された、高速かつ軽量でモダンなマルチトラック動画編集エディタです。複雑なサブスクリプションや不要な肥大化を排除し、動画・音声・画像・テキストの快適で直感的な編集ワークフローを提供します。

![minicut Interface](docs/screenshot.png)

---

## 開発経緯: どのように作られたか（バイブコーディング）

`minicut` は、**Google DeepMind Antigravity** AI コーディングアシスタントとのペアプログラミングを通じた「バイブコーディング（Vibe Coding）」の旅から生まれました。

初期のアーキテクチャ設計からスタートし、最新の **C++20** を用いてゼロから開発されました：
- **レンダリング & UI**: ハードウェアアクセラレーション対応の OpenGL 3.3 バックエンドと **Dear ImGui** を組み合わせ、KDE Plasma Breeze Dark テーマで洗練された外観を実現。
- **メディアエンジン**: ネイティブ **FFmpeg** パイプラインによる高速フレームデコード、オーディオリサンプリング、マルチスレッド動画エンコード（H.264/AAC, OGG/Theora）。
- **フォント描画 & 多言語対応**: **FreeType 2** による高品位ベクターグリフ描画。アラビア語のネイティブ連字・双方向テキスト（BiDi）処理や、日本語・韓国語の完全な CJK フォント対応を統合。
- **2系統の内蔵スクリプトエンジン**: サンドボックス化された **LuaJIT** および **Duktape JavaScript** を内蔵。タイムライン自動化や、独自のインタラクティブなドッキング可能ツールパネルの構築が可能です。

## 主な機能

- **マルチトラックタイムライン**: 無制限の動画・音声トラック。トラックヘッダーの並び替え、リネーム、Z-Depth（描画深度）管理に対応。
- **リアルタイムプレビュー & ダイレクト変形**: キャンバス上で位置座標、回転角度、拡大縮小、不透明度をリアルタイムに操作・プレビュー。
- **FreeType テキストジェネレータ**: リアルタイム入力プレビュー、アウトライン描画、文字間隔・行間隔調整、多言語（ラテン文字、キリル文字、日本語、韓国語、アラビア語）に対応したテキストアセット生成機能。
- **キーフレームアニメーション**: 不透明度フェード、位置移動、拡大縮小、音声ボリュームなどを線形補間で滑らかにアニメーション化。
- **拡張可能なスクリプト機能**: **Lua** または **JavaScript** でツールを作成可能：
  - `~/.config/minicut/autorun/` のスクリプトは、メニューバー下の「**ドック**」にアイコンボタンを自動登録。
  - `~/.config/minicut/scripts/` のスクリプトは、「**スクリプト**」メニューからいつでも実行可能。
- **幅広いメディア形式に対応**: MP4, MKV, MOV, WebM, AVI, OGG, OGV, OGM, MP3, WAV, AAC, FLAC, PNG, JPEG, WebP, BMP。
- **多言語 UI 対応**: 英語、日本語、韓国語、ウクライナ語、アラビア語。

## 基本的な使い方ガイド

### 1. インストール & 起動
ユーザーアカウントにインストールする場合：
```bash
./install.sh --user
```
ターミナルまたはデスクトップのアプリケーションランチャーから起動します：
```bash
minicut
# 既存のプロジェクトを開く場合:
minicut my_project.minicut
```

### 2. 基本的な編集手順

1. **アセットの読み込み**:
   - 「**プロジェクト > ビデオ / オーディオ / 画像のインポート...**」を選択するか、ファイルをウィンドウへ直接ドラッグ＆ドロップします。
   - 読み込まれた素材は「**クリップおよびアセット**」パネルに登録されます。
2. **テキストの追加**:
   - アセットブラウザの「**テキストを追加**」ボタン、または「**プロジェクト > テキストを追加**」をクリックします。
   - フォント、サイズ、文字色、アウトライン、配置を設定します。
   - 「**タイムラインに追加**」をクリックすると、再生ヘッドの位置にテキストクリップが配置されます。
3. **タイムラインの編集**:
   - クリップをトラック上にドラッグして配置します。
   - **Space** キーで再生／一時停止を切り替えます。
   - **S** キーを押すと、再生ヘッドの位置でクリップを分割できます。
   - **Ctrl** または **Shift** キーを押しながら複数クリップを選択し、まとめて移動できます。
4. **変形 & キーフレーム操作**:
   - タイムライン上のクリップを選択すると、「**コンテキストインスペクター**」に詳細プロパティが表示されます。
   - キーフレームを追加して、フェードイン／アウト、パン・ズーム効果、音量変化を演出できます。
5. **スクリプトツールの活用**:
   - メニューバー下の「**ドック**」のアイコンをクリックすると、自動実行ツールの操作パネルが開きます。
   - 「**スクリプト**」メニューから追加ツールを呼び出すこともできます。
6. **動画の書き出し**:
   - 「**ファイル > 動画のエクスポート (.mp4)...**」を選択して、完成した動画を出力します。
