# minicut

**minicut** — це швидкий, легкий і сучасний мультитрековий нелінійний відеоредактор, створений спеціально для робочих середовищ Linux. Він забезпечує простий, чутливий і надійний процес монтажу відео, аудіо, зображень та тексту без зайвого перевантаження інтерфейсу чи платних підписок.

![minicut Interface](docs/screenshot.png)

---

## Історія створення: Як це було зроблено (Вайб-кодинг)

Проєкт `minicut` народився у процесі інтерактивного "вайб-кодингу" (Vibe Coding) у парі зі штучним інтелектом **Google DeepMind Antigravity**.

Починаючи з базової концепції архітектури, застосунок було розроблено з нуля на сучасному стандарті **C++20**:
- **Рендеринг та інтерфейс**: Апаратне прискорення через OpenGL 3.3 у поєднанні з **Dear ImGui**, стилізованим під темну тему KDE Plasma Breeze Dark.
- **Медіа-рушій**: Власний конвеєр **FFmpeg** для швидкого декодування кадрів, ресемплювання звуку та багатопотокового рендерингу (H.264/AAC, OGG/Theora).
- **Типографіка та локалізація**: Високоякісний рендеринг векторних шрифтів через **FreeType 2** із підтримкою писемності RTL (арабська) та повним охопленням CJK (японська, корейська).
- **Подвійне середовище скриптів**: Ізольовані рушії **LuaJIT** та **Duktape JavaScript**, що дозволяють автоматизувати дії на таймлайні та створювати власні інтерактивні панелі інструментів.

---

## Основні можливості

- **Мультитрековий таймлайн**: Необмежена кількість доріжок відео та аудіо з можливістю зміни порядку перетягуванням, перейменування та налаштування глибини рендерингу (Z-Depth).
- **Попередній перегляд у реальному часі**: Зручне керування положенням (X/Y), масштабом, поворотом та непрозорістю.
- **Генератор тексту FreeType**: Генерація титрів та написів із живим переглядом, контурами, регулюванням інтервалів та повною підтримкою кирилиці, латиниці, CJK та арабської писемності.
- **Анімація ключових кадрів**: Лінійна інтерполяція для плавного регулювання прозорості, положення, масштабу та гучності аудіо.
- **Розширюваність через скрипти**: Підтримка створення інструментів на **Lua** або **JavaScript**:
  - Скрипти автозапуску в `~/.config/minicut/autorun/` додають кнопки-іконки на **Док**.
  - Додаткові скрипти в `~/.config/minicut/scripts/` доступні через меню **Скрипти**.
- **Підтримка форматів**: MP4, MKV, MOV, WebM, AVI, OGG, OGV, OGM, MP3, WAV, AAC, FLAC, PNG, JPEG, WebP, BMP.
- **Локалізація інтерфейсу**: Українська, English, 日本語, 한국어, العربية.

## Посібник користувача: Як користуватися minicut

### 1. Встановлення та запуск
Щоб встановити minicut для поточного користувача:
```bash
./install.sh --user
```
Запустіть `minicut` через термінал або системне меню програм:
```bash
minicut
# Або відкрийте існуючий проєкт:
minicut my_project.minicut
```

### 2. Основні кроки монтажу

1. **Імпорт медіафайлів**:
   - Оберіть **Проєкт > Імпортувати відео / аудіо / зображення...** або просто перетягніть файли у вікно програми.
   - Медіа з'явиться у списку **Кліпи та ресурси**.
2. **Додавання тексту**:
   - Натисніть кнопку **Додати текст** на панелі ресурсів або в меню **Проєкт > Додати текст**.
   - Налаштуйте шрифт, розмір, кольори, контур та вирівнювання.
   - Натисніть **Додати на таймлайн**, щоб розмістити текст у позиції курсору.
3. **Монтаж на часовій шкалі**:
   - Перетягуйте кліпи на відео- та аудіодоріжки.
   - Натискайте **Пробіл** для відтворення та паузи.
   - Натискайте клавішу **S** для розрізання кліпу на позиції курсору.
   - Утримуйте **Ctrl** або **Shift** для групового виділення кліпів.
4. **Трансформація та ключові кадри**:
   - Виберіть кліп на таймлайні, щоб переглянути його властивості в **Контекстному інспекторі**.
   - Додавайте ключові кадри для анімації появи/зникнення або руху.
5. **Використання скриптів**:
   - Натисніть іконку на **Доку** під меню для виклику панелі автозапуску.
   - Використовуйте готові або власні скрипти з меню **Скрипти**.
6. **Експорт відео**:
   - Оберіть **Файл > Експортувати відео (.mp4)...** для збереження фінального відеоролика.
