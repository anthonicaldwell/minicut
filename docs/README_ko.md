# minicut (v1.5.0)

[English](../README.md) | [العربية](README_ar.md) | [日本語](README_ja.md) | [한국어](README_ko.md) | [Українська](README_uk.md)

**minicut**은 리눅스 데스크톱 환경을 위해 특별히 설계된 빠르고 가벼우며 현대적인 멀티트랙 비선형 비디오 편집기입니다. 불필요한 기능 비대화나 복잡한 구독 모델 없이 비디오, 오디오, 이미지, 텍스트 편집을 위한 쾌적하고 반응성 높은 작업 환경을 제공합니다.

## 버전 1.5.0 새로운 기능

- 🚀 **차세대 Vulkan 렌더링 백엔드**:
  - 하드웨어 가속 Vulkan 1.2+ 파이프라인 탑재 (OpenGL 3.3 자동 폴백 지원).
- ⚡ **헤드리스 CLI 렌더링 (`--render`)**:
  - GUI를 띄우지 않고 터미널이나 CI/CD 파이프라인에서 직접 프로젝트를 비디오로 렌더링 (`minicut --render project.minicut --output out.mp4`).
- 📋 **일괄 처리 내보내기 큐 (Batch Queue)**:
  - 여러 프로젝트 파일을 대기열에 추가하고 순차적으로 연속 렌더링하는 전용 배치 처리 탭 제공.
- 🔄 **협업용 프리팹 핫 리로드 (Prefab Hot-Reloading)**:
  - 프리팹으로 포함된 `.minicut` 파일의 디스크 변경 사항을 감지하여 설정된 주기에 따라 자동으로 프로젝트 갱신.
- 🗂️ **에셋 브라우저 그리드 및 리스트 뷰**:
  - 썸네일 그리드 보기와 상세 목록 리스트 보기를 간편하게 전환.
- 🎛️ **수정자(Modifiers) 메뉴 재구성**:
  - AI 어시스턴트 도구, GLSL 셰이더 효과, 전체 클립 변형을 통합한 상단 '수정자' 메뉴.
- 🛠️ **설정 초기화 (`--reconfig`)**:
  - 손상된 사용자 설정을 기본값으로 복구하는 `minicut --reconfig` 스위치 지원.
- 🔊 **프로젝트 로드 시 오디오 스트림 보존**:
  - 프로젝트 로드 시 오디오 스트림을 자동으로 재추출하여 타임라인 오디오와 파형 손실 방지.

## 개발 배경: 어떻게 만들어졌는가 (바이브 코딩)

`minicut`은 차세대 AI 페어 프로그래밍 어시스턴트인 **Google DeepMind Antigravity**와 함께한 대화형 "바이브 코딩(Vibe Coding)" 여정을 통해 제작되었습니다.

초기 아키텍처 구상부터 시작하여 최신 **C++20**을 바탕으로 완전히 새롭게 구축되었습니다:
- **렌더링 및 UI**: 하드웨어 가속 OpenGL 3.3 백엔드와 **Dear ImGui**를 결합하고, 세련된 KDE Plasma Breeze Dark 테마를 적용했습니다.
- **미디어 엔진**: 고성능 프레임 디코딩, 오디오 리샘플링, 멀티스레드 비디오 인코딩(H.264/AAC, OGG/Theora)을 위한 네이티브 **FFmpeg** 파이프라인.
- **타이포그래피 및 다국어 지원**: **FreeType 2**를 통한 고해상도 벡터 글리프 렌더링. 아랍어 필기체 양방향(BiDi) 성형 및 한국어/일본어 완벽 CJK 글꼴 지원.
- **이중 임베디드 스크립팅 엔진**: 샌드박스화된 **LuaJIT** 및 **Duktape JavaScript** 런타임을 내장하여 타임라인 조작 자동화 및 맞춤형 대화형 도구 패널을 제작할 수 있습니다.

## 주요 기능

- **멀티트랙 타임라인**: 무제한 비디오 및 오디오 트랙. 트랙 헤더 순서 재배치, 이름 변경, Z-Depth(렌더링 깊이) 관리 지원.
- **실시간 미리보기 및 직접 변형**: 캔버스에서 위치 좌표, 회전 각도, 크기 조절, 불투명도를 실시간으로 조정하고 확인.
- **FreeType 텍스트 생성기**: 실시간 입력 미리보기, 외곽선 테두리, 자간/줄간격 조절, 다국어(한국어, 일본어, 라틴어, 키릴어, 아랍어) 지원 텍스트 에셋 생성 기능.
- **키프레임 애니메이션**: 불투명도 페이드, 위치 이동, 크기 조절, 오디오 볼륨을 선형 보간으로 부드럽게 애니메이션화.
- **확장 가능한 스크립팅 엔진**: **Lua** 또는 **JavaScript**로 도구 제작 가능:
  - `~/.config/minicut/autorun/`의 스크립트는 메뉴 표시줄 아래 '**도크**'에 아이콘 버튼을 자동으로 생성합니다.
  - `~/.config/minicut/scripts/`의 스크립트는 '**스크립트**' 메뉴에 즉시 등록됩니다.
- **폭넓은 미디어 포맷 지원**: MP4, MKV, MOV, WebM, AVI, OGG, OGV, OGM, MP3, WAV, AAC, FLAC, PNG, JPEG, WebP, BMP.
- **네이티브 다국어 UI 지원**: 한국어, English, 日本語, Українська, العربية.

## 기본 사용 가이드

### 1. 설치 및 실행
사용자 계정에 설치하려면 다음을 실행합니다:
```bash
./install.sh --user
```
터미널 또는 데스크톱 애플리케이션 메뉴에서 `minicut`을 실행합니다:
```bash
minicut
# 기존 프로젝트 열기:
minicut my_project.minicut
```

### 2. 기본 편집 단계

1. **미디어 에셋 가져오기**:
   - '**프로젝트 > 비디오 / 오디오 / 이미지 가져오기...**'를 선택하거나 파일을 창으로 직접 드래그 앤 드롭합니다.
   - 가져온 미디어는 '**클립 및 에셋**' 패널에 등록됩니다.
2. **텍스트 추가**:
   - 에셋 브라우저의 '**텍스트 추가**' 버튼 또는 '**프로젝트 > 텍스트 추가**'를 클릭합니다.
   - 글꼴, 크기, 색상, 외곽선 및 정렬을 설정합니다.
   - '**타임라인에 추가**'를 클릭하면 재생헤드 위치에 텍스트 클립이 배치됩니다.
3. **타임라인 조립**:
   - 클립을 비디오 및 오디오 트랙으로 끌어다 놓습니다.
   - **Space** 키를 눌러 재생 또는 일시 정지합니다.
   - **S** 키를 눌러 재생헤드 위치에서 클립을 분할합니다.
   - **Ctrl** 또는 **Shift** 키를 누른 상태에서 여러 클립을 다중 선택하여 함께 이동할 수 있습니다.
4. **변형 및 키프레임 설정**:
   - 타임라인의 클립을 선택하여 '**컨텍스트 인스펙터**'에서 속성을 확인합니다.
   - 키프레임을 추가하여 페이드인/아웃, 위치 이동, 오디오 볼륨을 애니메이션화합니다.
5. **스크립트 도구 활용**:
   - 메뉴 표시줄 아래 '**도크**'의 아이콘을 클릭하여 자동 실행 도구 패널을 엽니다.
   - '**스크립트**' 메뉴에서 추가 도구를 실행할 수도 있습니다.
6. **비디오 내보내기**:
   - '**파일 > 동영상 내보내기 (.mp4)...**'를 선택하여 완성된 비디오를 렌더링합니다.
