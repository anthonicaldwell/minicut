1. はじめに & アーキテクチャ

minicut は高速な LuaJIT スクリプトエンジンを内蔵しています。 タイムライン編集、クリップ配置、キーフレームアニメーション、自由なUIツールパネルの構築を自動化できます。

スクリプト配置ディレクトリ

配置場所起動契機 / 役割説明
~/.config/minicut/autorun/ 起動時自動実行 起動時に自動読み込みされ、メニューバー下の「ドック」にアイコンが登録されます。
~/.config/minicut/scripts/ メニュークリック時 メニューバーの「スクリプト」メニューに表示され、クリック時に実行されます。
~/.config/minicut/icons/ ドックアイコン画像 スクリプト名と一致するPNGアイコン画像（例: keyframe_animator.png）。

2. プラグインスクリプト構成

-- ============================================================================
-- スクリプト例: my_tool.lua
-- ============================================================================

local target_track = 0
local clip_scale = 1.0

function execute_action()
    minicut.push_undo()
    local clip_id = timeline.place_clip("sample.png", target_track, timeline.get_playhead(), 4.0)
    if clip_id and clip_id ~= "" then
        clip.set_scale(clip_id, clip_scale)
        timeline.add_keyframe(clip_id, "opacity", 0.0, 0.0)
        timeline.add_keyframe(clip_id, "opacity", 1.0, 1.0)
        minicut.set_status("クリップを配置しました: " .. clip_id)
    end
end

function choose_file()
    gui.file_dialog("ファイルを選択", function(path)
        if path and path ~= "" then minicut.set_status("選択: " .. path) end
    end)
end

function plugin:init_panel()
    gui.text("メディア配置ツール")
    gui.separator()
    target_track = gui.slider_int("トラック番号", target_track, 0, 4)
    clip_scale = gui.slider_float("拡大率", clip_scale, 0.1, 4.0)
    gui.button("参照...", choose_file)
    gui.button("再生ヘッド位置に配置", execute_action)
end

3. コアモジュール API

3.1. プロジェクト操作 (project / グローバル)

関数戻り値説明
project_save([path])boolean, stringプロジェクトを .minicut ファイルに保存します。
project_load(path)boolean, string指定パスからプロジェクトを読み込みます。
project.get_name()stringプロジェクト名を取得します。
project.set_name(name)voidプロジェクト名を設定します。

3.2. ネットワーク通信 (net)

関数戻り値説明
net.get(url)tableHTTP GET リクエストを実行します。
net.post(url, body)tableHTTP POST リクエストを送信します。
net.download(url, dest)booleanリモートファイルをローカルへ直接ダウンロードします。

3.3. タイムライン & トラック (timeline)

関数戻り値説明
timeline.get_playhead()number再生ヘッドの現在時刻（秒）を取得します。
timeline.set_playhead(t)void再生ヘッドを時刻 t 秒へ移動します。
timeline.place_clip(path, trk, t, dur)string動画/音声/画像をトラックに配置します。
timeline.add_keyframe(id, prop, t, val)voidアニメーションキーフレームを追加します。
timeline.clear_keyframes(id, prop)void特定プロパティの全キーフレームを消去します。
timeline.move_track_up(idx)voidトラックを上へ移動します。
timeline.move_track_down(idx)voidトラックを下へ移動します。
timeline.set_track_name(idx, name)voidトラック名を変更します。

3.4. クリップ変形 (clip)

関数戻り値説明
clip.get_position(id)number, number中心基準の (x, y) 座標を取得します。
clip.set_position(id, x, y)void中心座標を設定します。
clip.get_scale(id)numberスケール倍率（1.0 = 100%）を取得します。
clip.set_scale(id, s)voidスケール倍率を設定します。
clip.get_opacity(id)number不透明度 [0.0, 1.0] を取得します。
clip.set_opacity(id, o)void不透明度を設定します。
clip.get_volume(id)number音声ボリュームゲイン [0.0, 2.0] を取得します。
clip.set_volume(id, v)void音声ボリュームゲインを設定します。

3.5. GUI ウィジェット (gui)

関数戻り値説明
gui.text(text)voidテキストを表示します。
gui.text_colored(r, g, b, a, text)void色付きテキストを表示します。
gui.button(label, [callback])booleanボタンを表示しクリック時に実行します。
gui.slider_float(label, val, min, max)number浮動小数点スライダーを表示します。
gui.slider_int(label, val, min, max)integer整数スライダーを表示します。
gui.input_text(label, text)stringテキスト入力フィールドを表示します。
gui.file_dialog(title, cb, [filter])voidファイルダイアログを開き結果を返します。
