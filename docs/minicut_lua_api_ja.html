1. はじめに & アーキテクチャ

minicut は高速な組み込み LuaJIT スクリプトエンジンを搭載しています。タイムライン編集、クリップ配置、キーフレームアニメーション、独自のインタラクティブなドッキングツールパネルの構築をすべてスクリプトから自動化できます。

スクリプトディレクトリの配置

スクリプトやアイコンは、ユーザーの設定ディレクトリから自動的に検出・ロードされます：

ディレクトリ役割 / 実行タイミング概要
~/.config/minicut/autorun/ 起動時自動登録 エディタ起動時に自動実行され、メニューバー下の水平「ドック (Dock)」にアイコンボタンを生成します。
~/.config/minicut/scripts/ メニュクリック時実行 メインメニューバーの Scripts (スクリプト) メニューに登録され、クリック時にパネルを開いて実行します。
~/.config/minicut/icons/ ドック用アイコン画像 スクリプト名と同名の 32x32 PNG アイコン画像（例：quick_placement.lua 用の quick_placement.png）。

2. プラグインスクリプトの基本構造

minicut のスクリプトは直感的なコールバック構造を持ちます。タイムラインやクリップのロジック関数を記述し、plugin:init_panel() メソッド内で Dear ImGui の UI コントロールを登録します。 

-- ============================================================================
-- 基本スクリプト例: my_tool.lua
-- ============================================================================

local target_track = 0
local clip_scale = 1.25

-- タイムライン & クリップ操作ロジック
function execute_placement()
    minicut.push_undo()
    local path = "/path/to/media.mp4"
    local asset_id = project.import_video(path)
    local clip_id = timeline.place_video(target_track, asset_id, timeline.get_playhead(), 5.0)
    if clip_id ~= "" then
        clip.set_scale(clip_id, clip_scale)
        timeline.add_keyframe(clip_id, "opacity", 0.0, 0.0)
        timeline.add_keyframe(clip_id, "opacity", 1.0, 1.0)
        minicut.set_status("トラック " .. target_track .. " にメディアを配置しました")
    end
end

-- GUI パネル初期化
function plugin:init_panel()
    gui.text("メディア配置ツール")
    gui.separator()
    target_track = gui.slider_int("対象トラック", target_track, 0, 4)
    clip_scale = gui.slider_float("初期スケール", clip_scale, 0.1, 5.0)
    
    if gui.button("再生ヘッド位置に配置", execute_placement) then
        -- インライン処理も可能
    end
end
