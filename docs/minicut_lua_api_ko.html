minicut 비디오 편집기

임베디드 LuaJIT & 플러그인 API 참조 매뉴얼
LuaJIT 5.1 런타임 도킹 가능 도구 패널 도구 선반 도크 네트워크 라이브러리 (libcurl) FreeType 텍스트 생성

1. 소개 및 아키텍처

minicut은 고성능 LuaJIT 스크립팅 엔진을 내장하고 있습니다. 타임라인 자동화, 클립 배치, 키프레임 애니메이션, 맞춤형 인터랙티브 도구 패널을 자유롭게 제작할 수 있습니다.

스크립트 디렉터리 경로

경로실행 시점 / 역할설명
~/.config/minicut/autorun/ 시작 시 자동 실행 앱 실행 시 자동으로 로드되며 메뉴 표시줄 아래 '도크'에 아이콘 버튼이 생성됩니다.
~/.config/minicut/scripts/ 메뉴 클릭 시 메뉴 표시줄의 스크립트 메뉴에 표시되며 클릭 시 실행됩니다.
~/.config/minicut/icons/ 도크 아이콘 파일 스크립트 파일명과 일치하는 PNG 아이콘 이미지입니다.

2. 플러그인 스크립트 구조

-- ============================================================================
-- 스크립트 예제: my_tool.lua
-- ============================================================================

local target_track = 0
local clip_scale = 1.0

function execute_action()
    minicut.push_undo()
    local clip_id = timeline.place_clip("test_sample.png", target_track, timeline.get_playhead(), 4.0)
    if clip_id and clip_id ~= "" then
        clip.set_scale(clip_id, clip_scale)
        timeline.add_keyframe(clip_id, "opacity", 0.0, 0.0)
        timeline.add_keyframe(clip_id, "opacity", 1.0, 1.0)
        minicut.set_status("클립 배치 완료: " .. clip_id)
    end
end

function choose_file()
    gui.file_dialog("파일 선택", function(selected)
        if selected and selected ~= "" then
            minicut.set_status("선택된 파일: " .. selected)
        end
    end)
end

function plugin:init_panel()
    gui.text("미디어 배치 도구")
    gui.separator()
    target_track = gui.slider_int("트랙 번호", target_track, 0, 4)
    clip_scale = gui.slider_float("크기 비율", clip_scale, 0.1, 4.0)
    gui.button("파일 찾아보기...", choose_file)
    gui.button("재생헤드 위치에 배치", execute_action)
end

3. 코어 모듈 API

3.1. 프로젝트 제어 (project / 전역)

함수반환값설명
project_save([path])boolean, string프로젝트를 .minicut 파일로 저장합니다.
project_load(path)boolean, string지정된 경로의 프로젝트를 로드합니다.
project.get_name()string현재 프로젝트 이름을 가져옵니다.
project.set_name(name)void프로젝트 이름을 설정합니다.

3.2. 네트워크 라이브러리 (net)

함수반환값설명
net.get(url)tableHTTP GET 요청을 수행합니다.
net.post(url, body)tableHTTP POST 요청을 전송합니다.
net.download(url, dest)boolean원격 파일을 로컬 디스크에 직접 다운로드합니다.

3.3. 타임라인 및 트랙 (timeline)

함수반환값설명
timeline.get_playhead()number현재 재생헤드 위치(초)를 반환합니다.
timeline.set_playhead(t)void재생헤드를 t초 위치로 이동합니다.
timeline.place_clip(path, trk, t, dur)string비디오/오디오/이미지를 트랙에 배치합니다.
timeline.add_keyframe(id, prop, t, val)void애니메이션 키프레임을 추가합니다.
timeline.clear_keyframes(id, prop)void속성의 모든 키프레임을 제거합니다.
timeline.move_track_up(idx)void트랙을 위로 이동합니다.
timeline.move_track_down(idx)void트랙을 아래로 이동합니다.
timeline.set_track_name(idx, name)void트랙 이름을 변경합니다.

3.4. 클립 변형 (clip)

함수반환값설명
clip.get_position(id)number, number캔버스 중심 기준 (x, y) 좌표를 반환합니다.
clip.set_position(id, x, y)void중심 좌표를 설정합니다.
clip.get_scale(id)number크기 비율(1.0 = 100%)을 반환합니다.
clip.set_scale(id, s)void크기 비율을 설정합니다.
clip.get_opacity(id)number불투명도 [0.0, 1.0]를 반환합니다.
clip.set_opacity(id, o)void불투명도를 설정합니다.
clip.get_volume(id)number오디오 볼륨 게인 [0.0, 2.0]을 반환합니다.
clip.set_volume(id, v)void오디오 볼륨 게인을 설정합니다.

3.5. GUI 위젯 (gui)

함수반환값설명
gui.text(text)void텍스트 라벨을 렌더링합니다.
gui.text_colored(r, g, b, a, text)void색상 텍스트를 렌더링합니다.
gui.button(label, [callback])boolean버튼을 렌더링하고 클릭 시 콜백을 실행합니다.
gui.slider_float(label, val, min, max)number실수형 슬라이더를 렌더링합니다.
gui.slider_int(label, val, min, max)integer정수형 슬라이더를 렌더링합니다.
gui.input_text(label, text)string텍스트 입력 상자를 렌더링합니다.
gui.file_dialog(title, cb, [filter])void파일 대화상자를 열고 결과를 콜백으로 전달합니다.
