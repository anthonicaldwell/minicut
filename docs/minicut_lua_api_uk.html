Відеоредактор minicut

Вбудований рушій LuaJIT & Довідник з Plugin API
Середовище LuaJIT 5.1 Панелі інструментів Док інструментів Мережева бібліотека (libcurl) Генерація тексту FreeType

1. Вступ та архітектура

minicut має повністю вбудований, високопродуктивний рушій LuaJIT. Він забезпечує автоматизацію редагування таймлайну, розміщення медіа, анімацію ключових кадрів та створення власних панелей інструментів.

Каталоги розташування скриптів

РозташуванняЗапуск / РольОпис
~/.config/minicut/autorun/ Автозапуск при старті Скрипти завантажуються під час запуску та додають кнопку з іконкою на панель Доку під головним меню.
~/.config/minicut/scripts/ Вибір у меню Скрипти з'являються в меню Скрипти головного меню і запускаються за запитом користувача.
~/.config/minicut/icons/ Файли іконок Доку PNG іконки, що відповідають іменам скриптів (наприклад: keyframe_animator.png).

2. Архітектура плагіна

-- ============================================================================
-- Приклад скрипта: my_tool.lua
-- ============================================================================

local target_track = 0
local clip_scale = 1.0

function execute_action()
    minicut.push_undo()
    local clip_id = timeline.place_clip("test_sample.png", target_track, timeline.get_playhead(), 4.0)
    if clip_id and clip_id ~= "" then
        clip.set_scale(clip_id, clip_scale)
        timeline.add_keyframe(clip_id, "opacity", 0.0, 0.0)
        timeline.add_keyframe(clip_id, "opacity", 1.0, 1.0)
        minicut.set_status("Кліп успішно розміщено: " .. clip_id)
    end
end

function choose_file()
    gui.file_dialog("Оберіть файл", function(selected)
        if selected and selected ~= "" then
            minicut.set_status("Обрано: " .. selected)
        end
    end)
end

function plugin:init_panel()
    gui.text("Інструмент розміщення медіа")
    gui.separator()
    target_track = gui.slider_int("Номер доріжки", target_track, 0, 4)
    clip_scale = gui.slider_float("Масштаб", clip_scale, 0.1, 4.0)
    gui.button("Огляд файлів...", choose_file)
    gui.button("Розмістити на курсорі", execute_action)
end

3. Опис основних модулів

3.1. Керування проєктом (project / Глобальні)

ФункціяПовертаєОпис
project_save([path])boolean, stringЗберігає стан проєкту у файл .minicut.
project_load(path)boolean, stringЗавантажує проєкт за вказаним шляхом.
project.get_name()stringПовертає поточну назву проєкту.
project.set_name(name)voidВстановлює назву проєкту.

3.2. Мережева бібліотека (net)

ФункціяПовертаєОпис
net.get(url)tableВиконує запит HTTP GET.
net.post(url, body)tableНадсилає запит HTTP POST.
net.download(url, dest)booleanЗавантажує віддалений файл безпосередньо на диск.

3.3. Часова шкала та доріжки (timeline)

ФункціяПовертаєОпис
timeline.get_playhead()numberПовертає поточну позицію курсору в секундах.
timeline.set_playhead(t)voidПереміщує курсор у позицію t секунд.
timeline.place_clip(path, trk, t, dur)stringРозміщує відео, аудіо або зображення на доріжці.
timeline.add_keyframe(id, prop, t, val)voidДодає ключовий кадр анімації (opacity, volume тощо).
timeline.clear_keyframes(id, prop)voidВидаляє всі ключові кадри для властивості.
timeline.move_track_up(idx)voidПереміщує доріжку вгору в стеку.
timeline.move_track_down(idx)voidПереміщує доріжку вниз в стеку.
timeline.set_track_name(idx, name)voidПерейменовує доріжку за індексом.

3.4. Трансформація кліпів (clip)

ФункціяПовертаєОпис
clip.get_position(id)number, numberОтримує координати (x, y) відносно центру.
clip.set_position(id, x, y)voidВстановлює координати центру кліпу.
clip.get_scale(id)numberОтримує коефіцієнт масштабування (1.0 = 100%).
clip.set_scale(id, s)voidВстановлює коефіцієнт масштабування.
clip.get_opacity(id)numberОтримує рівень непрозорості [0.0, 1.0].
clip.set_opacity(id, o)voidВстановлює непрозорість кліпу.
clip.get_volume(id)numberОтримує підсилення гучності [0.0, 2.0].
clip.set_volume(id, v)voidВстановлює підсилення гучності.
