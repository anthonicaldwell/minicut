1. Introduction & Architecture

minicut features a fully embedded, high-performance LuaJIT scripting engine. minicut enables complete automation, timeline editing, clip keyframing, and custom interactive dockable tool panels.

Script Directory Locations

Scripts and icons are discovered in the user configuration directory:

LocationTrigger / RoleDescription
~/.config/minicut/autorun/ Startup / Auto-register Scripts execute on startup and generate an icon button on the horizontal Tool Shelf Dock below the main menu bar.
~/.config/minicut/scripts/ Menu Click / On Demand Scripts appear in the top-level Scripts menu on the main menu bar. Clicking runs the script and opens its tool panel.
~/.config/minicut/icons/ Dock Icon Asset PNG icon images matching script stems (e.g., keyframe_animator.png for keyframe_animator.lua).

2. Plugin Script Architecture

Every minicut script defines timeline and clip manipulation callbacks, followed by a plugin:init_panel() method that registers Dear ImGui UI controls. 

-- ============================================================================
-- Example Base Script: my_tool.lua
-- ============================================================================

local target_track = 0
local clip_scale = 1.25

function execute_placement()
    minicut.push_undo()
    local path = "/path/to/media.mp4"
    local clip_id = timeline.place_clip(path, target_track, timeline.get_playhead(), 5.0)
    if clip_id and clip_id ~= "" then
        clip.set_scale(clip_id, clip_scale)
        timeline.add_keyframe(clip_id, "opacity", 0.0, 0.0)
        timeline.add_keyframe(clip_id, "opacity", 1.0, 1.0)
        minicut.set_status("Placed media clip on track " .. target_track)
    end
end

function plugin:init_panel()
    gui.text("Media Placement Tool")
    gui.separator()
    target_track = gui.slider_int("Track Lane", target_track, 0, 4)
    clip_scale = gui.slider_float("Initial Scale", clip_scale, 0.1, 5.0)
    
    gui.button("Place Clip At Playhead", execute_placement)
end
