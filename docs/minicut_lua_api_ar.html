محرر الفيديو minicut

دليل مرجعي لبيئة البرمجة LuaJIT والإضافات البرمجية
محرك LuaJIT 5.1 لوحات أدوات قابلة للتثبيت منصة الأدوات (Dock) مكتبة الشبكة (libcurl) توليد النصوص عبر FreeType

1. المقدمة والبنية البرمجية

يحتوي برنامج minicut على محرك برمجي مدمج عالي الأداء بلغة LuaJIT. يتيح المحرك أتمتة عمليات المخطط الزمني بالكامل، إدراج الوسائط، تحريك الإطارات المفتاحية (Keyframing)، وبناء لوحات تحكم تفاعلية مخصصة.

مسارات مجلدات السكربتات

المساروقت التشغيل / الدورالوصف
~/.config/minicut/autorun/ التشغيل التلقائي عند البدء يتم تحميل السكربتات تلقائياً عند بدء التشغيل وتنشئ زراً في منصة الأدوات (Dock) أسفل شريط القوائم.
~/.config/minicut/scripts/ النقر في شريط القوائم تظهر السكربتات في قائمة البرمجيات (Scripts) ويتم تشغيلها عند اختيارها من قبل المستخدم.
~/.config/minicut/icons/ أيقونات منصة الأدوات ملفات أيقونات PNG مطابقة لاسم السكربت (مثال: keyframe_animator.png).

2. بنية ملف السكربت البرمجي

-- ============================================================================
-- سكربت توضيحي: my_tool.lua
-- ============================================================================

local target_track = 0
local clip_scale = 1.0

function execute_action()
    minicut.push_undo()
    local clip_id = timeline.place_clip("sample.png", target_track, timeline.get_playhead(), 4.0)
    if clip_id and clip_id ~= "" then
        clip.set_scale(clip_id, clip_scale)
        timeline.add_keyframe(clip_id, "opacity", 0.0, 0.0)
        timeline.add_keyframe(clip_id, "opacity", 1.0, 1.0)
        minicut.set_status("تم إدراج المقطع: " .. clip_id)
    end
end

function choose_file()
    gui.file_dialog("اختر ملفاً", function(selected)
        if selected and selected ~= "" then
            minicut.set_status("تم اختيار: " .. selected)
        end
    end)
end

function plugin:init_panel()
    gui.text("أداة إدراج الوسائط")
    gui.separator()
    target_track = gui.slider_int("رقم المسار", target_track, 0, 4)
    clip_scale = gui.slider_float("المقياس", clip_scale, 0.1, 4.0)
    gui.button("تصفح الملفات...", choose_file)
    gui.button("إدراج عند المؤشر", execute_action)
end

3. مكتبات ووحدات النظام البرمجية

project.set_name(name)voidتعيين اسم المشروع.

3.2. مكتبة الشبكة والإنترنت (net)

الدالةالقيمة المرجعةالوصف

3.3. المخطط الزمني والمسارات (timeline)

الدالةالقيمة المرجعةالوصف
timeline.get_playhead()numberموقع مؤشر التشغيل بالثواني.
timeline.set_playhead(t)voidتحريك مؤشر التشغيل إلى الثانية t.
timeline.place_clip(path, trk, t, dur)stringإدراج مقطع فيديو أو صوت أو صورة في المسار.
timeline.add_keyframe(id, prop, t, val)voidإضافة إطار مفتاحي للحركة (الشفافية، الصوت، إلخ).
timeline.clear_keyframes(id, prop)voidمسح كافة الإطارات المفتاحية للخاصية.
timeline.move_track_up(idx)voidتحريك المسار لأعلى.
timeline.move_track_down(idx)voidتحريك المسار لأسفل.
timeline.set_track_name(idx, name)voidإعادة تسمية المسار.

3.4. خصائص وتحويلات المقاطع (clip)

الدالةالقيمة المرجعةالوصف

clip.get_scale(id)numberالحصول على معامل المقياس (1.0 = 100%).

clip.get_volume(id)numberالحصول على مضخم الصوت [0.0, 2.0].
clip.set_volume(id, v)voidتعيين مستوى الصوت.
